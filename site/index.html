How it works

Three steps, one real SOC pipeline

Play with Docker gives you a free, disposable Linux box with Docker already installed — right in your browser. This project runs on it exactly as it runs anywhere else.

1

Sign in with a free Docker Hub account

Click "Launch Free Lab," sign in with a Docker ID (free, ~1 minute if you don't have one), then click "+ ADD NEW INSTANCE." You get a real terminal.

2

Paste four commands

Clone the repo and run the demo — copy the block below straight into the terminal Play with Docker gives you.

3

Click the port badges

Play with Docker auto-detects open ports and shows clickable links at the top of the screen — click 3000 for the vulnerable app, 5601 for the Kibana dashboard full of alerts.

Copy, paste, done

Run the whole thing

# inside your Play with Docker terminal
apk add --no-cache git make
git clone __GITHUB_URL__.git
cd mini-soc-lab
make demo
⏱
First run takes 3–6 minutes — it's pulling Suricata, Elasticsearch, Kibana and the vulnerable target app. Every run after that is fast. The whole session (and everything in it) is destroyed after 4 hours — spin up a fresh one anytime, free, forever.
